# Henry's mini-exercise cheat sheets

Study sheets for demoing Henry's four individual mini-exercises to the TAs. The format follows the PA1 sheets (`115A-535652-3DGP-PA1/docs/cheatsheets/`).
Per the course rules (`docs/references/course/mini-exercises.md`), the TA will ask you to **demo the program, present the source code, explain the method, modify it live, and point out which parts are new**.

| Demo | Exercise | Folder (under `Assets/_Project/MiniExercises/Henry/`) | Issue |
|---|---|---|---|
| **Nov 16** | 4.C.4 Character interaction with objects (100 dominoes) | `4C4_ObjectInteraction/` | #57 |
| **Nov 16** | 4.E.3 Game UI (club cards, time/power bars, minimap) | `4E3_GameUI/` | #58 |
| **Dec 14** | 4.A.1 Animation of a hierarchical model (one-handed golf swing) | `4A1_HierarchicalModel/` | #59 |
| **Dec 14** | 4.A.3 Game portals (hub, 3 areas, locked portal) | `4A3_GamePortals/` | #60 |

| Sheet | Use it for |
|---|---|
| [01 C#](01-csharp-cheatsheet.md) | C# syntax in these scripts, compared with Python / TypeScript |
| [02 Unity lifecycle](02-unity-lifecycle-cheatsheet.md) | which Unity method runs when, with the exercise code; frame-by-frame walkthroughs |
| [03 Architecture](03-architecture-cheatsheet.md) | Core vs exercise code, component maps, design patterns, honest trade-offs |
| [04 Requirements](04-requirements-cheatsheet.md) | each spec requirement: where it is, a 20-second demo, what to say, **what's new vs PA1** |
| [05 Demo prep](05-demo-prep-cheatsheet.md) | pre-flight checklist, speeches, drills, E3 export, what to do if something breaks |
| [06 TA questions](06-ta-questions-cheatsheet.md) | "explain this" answers with code, "change X" snippets, tricky questions |

Conventions: code is referenced by **file + method name** (not line numbers, which change when you edit). Core scripts are in `Assets/_Project/Scripts/Core/`, exercise scripts in each exercise's `Scripts/` folder. The snippets in sheet 6 were written against the current code but **not compiled**. Try each one once before the demo.
Each exercise README (in its folder) has the controls, the requirement checklist and the "TA modification points" table. These sheets add to the READMEs; they don't replace them.
