# Course project instruction

Source: `00_3DGP_Project_Instruction.docx`

## Preparation
- **Must** use the instructor's **pptx template** for the slides. Only the background may change.
- **Must** use the instructor's **report template** (see [report-template.md](report-template.md)).
- **Must** do a **live demo** and bring the program source code.
- Not using the templates reduces the score.

## Hand in on paper at the start of the presentation
- **Form A** (presentation evaluation) and **Form B** (group program evaluation), printed.
- Both forms: group ID, each member's name and student ID.
- Form B: write down explicitly the items you or the group finished, score each item against the criteria, and write the total group score. The team fills these in manually in Word.

## Upload to E3 before the deadline
Zip everything as `GroupID_GameName.zip`:
1. **Report** as a PDF, using the template.
2. **Teaser demo video**, at least 3–5 minutes (longer if appropriate). Form A says the teaser shown in the slides should be 1–3 min. See the gap analysis.
3. **Slides**, using the template.
4. **Program source code**, zipped as `Group_ID_Game_Name`. If it's too large, upload a readme with a cloud download link instead.

## Presentation-day procedure
1. Hand in Forms A and B.
2. Present with the pptx.
3. **Live demo:** complete **all game levels and finish the game**. Show **all particle effects, sound effects, and every item listed on Form B**.
4. Q&A.
5. TAs check the program and each member's contribution, then adjust or confirm the Form B items and scores.
