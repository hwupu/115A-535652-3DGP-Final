# Form B — Program evaluation

Source: `3DGP_Form_B_Program_Rubrics.docx`. The paper form is filled in manually. This file only records the rubric.

- Max **100 pts**. Write down explicitly which items were finished and how many of each. TAs verify the claims at the source check.
- Every finished item must also appear in the ppt.
- Per-item score tags: **Above average 6 pts**, Average 3–5 pts, Below average 0–2 pts.
- The teacher also rates the overall impression (game integrity, play experience, scene modeling, innovation).

## Hard rule: one level per member
**One game level per team member, with totally different scenes and monsters in each level.** Each missing level costs **−30 pts**. With 3 members we need **3 levels**.

## Core items (6 pts each for "above average")
| Item | Above average (6) | Average (3–5) |
|---|---|---|
| Program source (team LOC) | **800+** lines | 500–800 |
| Character leveling | **≥ 5 levels and ≥ 5 different skills** | 3–4 levels, 3–4 skills |
| Scene design and layout | **≥ 100 objects** | 50–99 |
| Particle systems (attractive, not too bright) | **≥ 5 per team member** | 3–4 per member |
| Sound effects | **≥ 4 per team member** | 3 per member |
| Material + texture mapping | **All** objects, floor, terrain, walls fully texture-mapped | More than half |
| Miscellaneous items (menu, save/load, settings, character selection, trading system, ...) | **≥ 5 items** | 3–4 |
| GUI items on screen (XP/energy/stamina bar, score, minimap, inventory, character profile, ...) | **≥ 5 different** | 3–4 |
| Finite state machines (**each ≥ 4 states**) | **≥ 5 FSMs** | 3–4 |
| Monster/NPC skills | **≥ 5 skills** | 3–4 |
| Environment interaction (portal, trap, item pickup, buttons/levers, dynamically changing environment, ...) | **≥ 5 different ways** | 3–4 |
| Game/character control | **Mouse + keyboard** (and/or other devices) | Keyboard only or mouse only |
| Others | Our own items (optional) | |

## Game enhancement (extra points)
| Item | Scoring |
|---|---|
| Extra game level | +5 per extra level, up to +10. Content must be totally different (models, monsters, play style). |
| Simulation technique | **+2 each if implemented by our team** (+1 if not), up to +10. Examples: steering (wander, pursuit, leader following, evasion), group alignment and separation, deformable objects, collision detection and handling. |
| Network game | Up to +10, at least 2 players |
| Artwork / manual objects (made by us, important and meaningful) | Above average: **≥ 3**; average: 1–2 |
| Lighting effects | Above average: **≥ 3 different lighting effects in different regions per level**; average: 1–2 |
| Scene effects (fog, shadow, day/night, skies, lens flare) | Above average: **≥ 5**; average: 3 |
| Item/object composition (combine items into new items) | Above average: **≥ 3** composited objects; average: 1–2 |
| Other techniques | Our own items |

## Individual bonus (LOC written by one member)
| LOC per member | Bonus |
|---|---|
| ≥ 3000 | +10 |
| 2000–3000 | +5 to +9 |
| 1500–2000 | +1 to +4 |

LOC per member must also be reported in the slides and the report, so we need a repeatable way to count it (e.g., by git author).
