# Final report — required structure

Source: `3DGP_final_project_report_template.docx`. The report itself is written in the Word template and submitted as a PDF. This file lists the required content so we can collect material during the sprints.

General rules: **use the template**. Include all the ppt items plus a **SWOT analysis**. Describe the work items in detail. Use as many game snapshots as possible: game scenes, gameplay, levels, particle systems. Extra sections are allowed.

Header fields: Group ID, Game Title, Member List, Game Name.

**Bonus:** extra items of good quality.
**Penalties:** missing Tasks and Contributions −10, missing Acknowledgement −5, missing Reference List −5.

## Evidence to collect during development
Screenshots of each level (≥ 4 per level), particle and sound clips, FSM diagrams, an architecture diagram, per-member LOC and git history, sprint records (for the Scrum section), and artwork figures.
