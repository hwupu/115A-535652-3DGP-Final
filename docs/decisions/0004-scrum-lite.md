# 0004-scrum-lite — Lightweight Scrum
- Status: Accepted
- Date: 2026-10-12
- Deciders: Product Owner (team) with Claude as scrum master

## Context
3 people, course deadline, AI agents as team members.

## Decision
1-week sprints, GitHub Issues + Project board, no daily standup meeting (async notes in the sprint file), 20-minute planning+review+retro combined. Humans own the product (priorities, acceptance). Agents act as Scrum Master first (backlog grooming, sprint docs, process hygiene), then as Developers once the backlog and scene foundations exist. Details: `docs/scrum/process.md`.

## Consequences
Minimal ceremony; role switch to Developer happens when the PO says so (record in a new ADR).
